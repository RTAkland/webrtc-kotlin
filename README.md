# kotlin-webrtc

A Kotlin native WebRTC DataChannel wrapper
of [libdatachannel](https://github.com/paullouisageneau/libdatachannel) based on kotlin cinterop

# Supported platforms

|         | x64 | arm64 |
|---------|:---:|:-----:|
| Linux   | ✔  |  ✔   |
| macOS   |  -  |  ✔   |
| Windows | ✔  |   -   |
